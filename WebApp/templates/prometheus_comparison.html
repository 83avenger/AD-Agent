AD-Agent + Prometheus & Grafana

Not a replacement comparison — a different category. Prometheus/Grafana is a generic metrics-and-dashboards platform with no idea what a GPO, a KEV entry, or a stale WinRM cert is. AD-Agent is the other way around: deep AD/security domain knowledge, but no interest in reinventing time-series storage or alert routing. AD-Agent's /metrics endpoint exports its findings in Prometheus format so you can get both.

Wiring them together

  1. Point a Prometheus scrape config at http://<jump-server>:5000/metrics
  2. Import grafana/ad-agent-dashboard.json into Grafana as a data source-linked dashboard
  3. Load grafana/ad-agent-alerts.yml into Prometheus (rule_files: in prometheus.yml) for the prebuilt AD-specific alert rules
  4. If Phase 5 (IIS reverse proxy) is deployed, allowlist the Prometheus server's IP for unauthenticated access to /metrics specifically — scrapers can't do interactive Windows Authentication
