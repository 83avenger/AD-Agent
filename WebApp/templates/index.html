Discovery Only

Discovery Targets

Leave unchecked for a quick, targeted scan of just the CIDR/IP below. Checking this also pulls every AD computer object (can be thousands) into the same run — only check it when you actually want a full AD resync, not for a one-off host lookup.

Accepts CIDR (10.0.0.0/24, /16 to /32), dash ranges (10.15.2.1 - 10.15.2.50, max 65,536 addresses), single IPs, and hostnames — a hostname is resolved to its current IP at scan time, so it stays correct after a DHCP renewal.

Leaving both boxes above unchecked (the default) collects installed software from every reachable Windows host found — this is the slower, more thorough option.
